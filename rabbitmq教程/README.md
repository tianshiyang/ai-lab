# RabbitMQ 教程

八讲,从收发第一条消息到完整的事件驱动架构。业务数据全部写死在代码里,不用准备任何东西——除了你的手。

**仓库里不带你抄的现成 .py**——每个脚本的全文代码只存在于讲义里,照着敲出来、存到对应目录,才是这套教程的用法(唯一例外:第 8 讲的 `reset.py` 是清场工具,自带)。配合固定的学习节奏:

```
读开场图(这讲解决什么问题) → 对着讲义敲代码(建议手敲,别复制;
跑脚本、做实验(讲义"跑起来"一节给了原样可复制的命令和预期输出)
→ 回答检核题(答不上再回头翻)
```

讲义里的 **「敲黑板」** 块是必须长进肌肉记忆的规矩,忘了随时回来扫;每讲开头的流程图是全讲的地图,学完回头看一眼,能自己复述出来才算过关。

## 怎么跑

- 环境:先把讲义里的代码**敲到对应章节目录、按讲义里的文件名存盘**(比如第 1 讲敲成 `rabbitmq教程/01-收发第一条消息/send.py`),然后在仓库根目录 `uv run python "<脚本路径>"` 跑——每讲讲义里都给了原样可复制的命令;
- 连接地址:根目录 `.env` 的 `RABBITMQ_URL`,课程用独立 vhost `lab`,和你服务器上的业务环境(`clouddisk` vhost)互不相干,随便折腾;
- **管理台是第二教材**:`http://62.234.16.180:15672`(账号密码同 .env 里 URL 那对)。每讲跑脚本时开着 Queues/Exchanges 页,消息的进出、堆积、死信的"一跳",在页面上都是肉眼可见的——MQ 的概念,看一眼队列页胜过读三段文字;
- 队列名各讲带 `ch1~ch8` 或 `shop` 前缀,讲与讲互不干扰;演示脚本跑完大多会自己清理,残留的去管理台删掉即可。

## 功能分级速查(找工作/干活前扫一眼)

**必须掌握**:收发基本操作、工作队列与手动 ack、prefetch、三种交换机、持久化、publisher confirm 与 mandatory、死信队列、TTL+死信做延迟、幂等消费。

**了解即可**:headers 交换机、优先级队列、RPC 模式、quorum/lazy 队列、集群与 Federation、流控告警、管理 HTTP API(要会用 curl 查队列)。

## 给学过一半又卡住的你

这套教程是推倒重来的版本。如果你上一轮被一堆 JSON 数据文件劝退过,放心,这次:**没有作业式的拼数据环节**——每段剧情的订单、日志、工单全部写死在讲义的代码里,你的任务就是敲、跑、看、想——代码不用你设计,照着敲就能体会每一行为什么那么写。卡在某一讲就把那一讲的检核题拿出来自问,答不上再回头翻对应小节。

另外,课程根目录还放了份 [aio-pika配置速查.md](aio-pika配置速查.md):全部常用 API 的参数级备忘,当字典用——忘了某参数叫什么、默认值是什么,翻它比翻讲义快。八讲走完,你可以试试不看它自己默写一份,写得出来就算出师了。
