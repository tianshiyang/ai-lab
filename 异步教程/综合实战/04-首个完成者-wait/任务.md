# 04 · 首个完成者：`asyncio.wait`

## 需求

- 创建快任务（`0.1s`）和慢任务（`0.3s`）。
- 用 `wait(..., return_when=FIRST_COMPLETED)` 取得 `done` 和 `pending`。
- 打印获胜任务的结果。
- 显式取消 `pending`，并用 `gather(..., return_exceptions=True)` 回收它们。

## 验收

```text
wait 在约 0.1s 返回
done 中是快任务
慢任务会收到取消
```

`wait` 不会替你取消慢任务；“最快者胜出”是你写出的策略。

## 参考答案

```python
import asyncio


async def demo_wait() -> None:
    async def work(name: str, delay: float) -> str:
        try:
            await asyncio.sleep(delay)
            return name
        except asyncio.CancelledError:
            print(f"{name} 被取消")
            raise

    tasks = {
        asyncio.create_task(work("快", 0.1)),
        asyncio.create_task(work("慢", 0.3)),
    }
    done, pending = await asyncio.wait(tasks, return_when=asyncio.FIRST_COMPLETED)

    winner = next(iter(done))
    print("获胜：", winner.result())

    for task in pending:
        task.cancel()
    await asyncio.gather(*pending, return_exceptions=True)


asyncio.run(demo_wait())
```
