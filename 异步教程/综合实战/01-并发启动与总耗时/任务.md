# 01 · 并发启动与总耗时

## 需求

实现两个 demo：

- `fetch_user()` 等 `0.2s`，返回 `"用户"`；`fetch_score()` 等 `0.3s`，返回 `"积分"`。
- 串行 demo 直接连续 `await` 两个函数。
- 并发 demo 先用 `create_task()` 启动两个函数，再用 `gather()` 收集结果。
- 用 `time.perf_counter()` 打印各自耗时。

## 验收

```text
串行约 0.5s
并发约 0.3s
```

结论：先创建两个 Task，两个计时器才能重叠；创建完立刻等待一个 Task，再启动另一个，仍是串行。

## 参考答案

```python
import asyncio
import time


async def fetch_user() -> str:
    await asyncio.sleep(0.2)
    return "用户"


async def fetch_score() -> str:
    await asyncio.sleep(0.3)
    return "积分"


async def demo_serial() -> None:
    start = time.perf_counter()
    user = await fetch_user()
    score = await fetch_score()
    print(user, score, f"{time.perf_counter() - start:.1f}s")


async def demo_concurrent() -> None:
    start = time.perf_counter()
    user_task = asyncio.create_task(fetch_user())
    score_task = asyncio.create_task(fetch_score())
    user, score = await asyncio.gather(user_task, score_task)
    print(user, score, f"{time.perf_counter() - start:.1f}s")


async def main() -> None:
    await demo_serial()
    await demo_concurrent()


asyncio.run(main())
```
