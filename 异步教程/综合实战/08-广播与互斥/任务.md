# 08 · 广播与互斥：`Event`、`Lock`

## 需求

写两个 demo：

1. 两个 waiter 先 `await event.wait()`；确认它们都已开始等待后调用 `event.set()`，两个 waiter 都要继续。
2. 三个协程同时给共享的 `count` 加一；在“读取旧值”和“写回新值”之间放 `await sleep(0)`。用 `Lock` 保证最终值是 `3`。

## 验收

```text
Event：A、B 都被唤醒
Lock：最终 count 为 3
```

`Event` 广播“状态已成立”；`Lock` 保护跨 `await` 的共享读改写。

## 参考答案

```python
import asyncio


async def demo_event() -> None:
    event = asyncio.Event()

    async def waiter(name: str) -> None:
        await event.wait()
        print(name, "继续执行")

    tasks = [asyncio.create_task(waiter("A")), asyncio.create_task(waiter("B"))]
    await asyncio.sleep(0)
    event.set()
    await asyncio.gather(*tasks)


async def demo_lock() -> None:
    lock = asyncio.Lock()
    state = {"count": 0}

    async def increment() -> None:
        async with lock:
            old_count = state["count"]
            await asyncio.sleep(0)
            state["count"] = old_count + 1

    await asyncio.gather(*(increment() for _ in range(3)))
    print("count =", state["count"])


async def main() -> None:
    await demo_event()
    await demo_lock()


asyncio.run(main())
```
