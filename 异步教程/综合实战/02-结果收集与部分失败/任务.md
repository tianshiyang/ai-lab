# 02 · 结果收集与部分失败

## 需求

任务 A 在 `0.1s` 返回 `"A"`，B 在 `0.2s` 抛出 `ValueError`，C 在 `0.3s` 返回 `"C"`。

- 用 `gather(..., return_exceptions=True)` 收集三项结果。
- 重新创建三项任务，用 `as_completed()` 按完成顺序处理；每项异常都要捕获，不能让循环中断。

## 验收

```text
gather：约 0.3s 后一次得到 ["A", ValueError, "C"]
as_completed：约 0.1s 得到 A；0.2s 处理 B 的异常；0.3s 得到 C
```

## 参考答案

```python
import asyncio


async def work(name: str, delay: float, fail: bool = False) -> str:
    await asyncio.sleep(delay)
    if fail:
        raise ValueError(f"{name} 失败")
    return name


async def demo_gather() -> None:
    results = await asyncio.gather(
        work("A", 0.1),
        work("B", 0.2, fail=True),
        work("C", 0.3),
        return_exceptions=True,
    )
    print(results)


async def demo_as_completed() -> None:
    tasks = [
        asyncio.create_task(work("A", 0.1)),
        asyncio.create_task(work("B", 0.2, fail=True)),
        asyncio.create_task(work("C", 0.3)),
    ]
    for completed in asyncio.as_completed(tasks):
        try:
            print("成功：", await completed)
        except ValueError as error:
            print("失败：", error)


async def main() -> None:
    await demo_gather()
    await demo_as_completed()


asyncio.run(main())
```
