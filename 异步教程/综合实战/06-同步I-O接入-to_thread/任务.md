# 06 · 同步 I/O 接入：`to_thread`

## 需求

- 定义同步函数 `blocking_work()`：用 `time.sleep(0.2)` 模拟阻塞 I/O，并返回 `"同步结果"`。
- 定义协程 `heartbeat()`：每 `0.05s` 打印一次心跳，共 4 次。
- 用 `gather()` 同时运行 `heartbeat()` 和 `to_thread(blocking_work)`。

## 验收

```text
同步函数执行期间仍能看到心跳
总耗时约 0.2s
最终能得到 "同步结果"
```

关键：`to_thread` 把同步函数放到工作线程；它不把函数内部改造成协程，也不保证它最后完成。

## 参考答案

```python
import asyncio
import time


async def demo_to_thread() -> None:
    def blocking_work() -> str:
        time.sleep(0.2)
        return "同步结果"

    async def heartbeat() -> None:
        for index in range(4):
            print("心跳", index)
            await asyncio.sleep(0.05)

    _, result = await asyncio.gather(
        heartbeat(),
        asyncio.to_thread(blocking_work),
    )
    print(result)


asyncio.run(demo_to_thread())
```
