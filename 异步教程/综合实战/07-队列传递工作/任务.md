# 07 · 队列传递工作：`Queue`

## 需求

- 创建 `Queue(maxsize=2)`。
- producer 放入 `0`、`1`、`2`，最后放入 `None` 作为停止哨兵。
- consumer 逐项 `get()`、打印；无论拿到普通数据还是哨兵，都必须调用一次 `task_done()`。
- 等 producer 结束后，调用 `queue.join()`，最后再等待 consumer。

## 验收

```text
三个数字都恰好被消费一次
程序能在 join 后正常结束
```

`join()` 等的是每个 `put()` 都对应一次 `task_done()`，不是“队列看起来为空”。

## 参考答案

```python
import asyncio


async def demo_queue() -> None:
    queue: asyncio.Queue[int | None] = asyncio.Queue(maxsize=2)

    async def producer() -> None:
        for item in range(3):
            await queue.put(item)
            print("放入", item)
        await queue.put(None)

    async def consumer() -> None:
        while True:
            item = await queue.get()
            try:
                if item is None:
                    return
                print("处理", item)
            finally:
                queue.task_done()

    producer_task = asyncio.create_task(producer())
    consumer_task = asyncio.create_task(consumer())
    await producer_task
    await queue.join()
    await consumer_task


asyncio.run(demo_queue())
```
