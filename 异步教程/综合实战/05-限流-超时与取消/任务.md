# 05 · 限流、超时与取消

## 需求

写三个独立 demo：

1. `Semaphore(2)` 管理 5 个各等 `0.1s` 的任务；打印进入 / 离开，观察同一时刻最多两个任务在运行。
2. 用 `asyncio.timeout(0.05)` 包住一个 `sleep(0.2)`，在外层捕获 `TimeoutError`。
3. 用 `wait_for()` 给一个 `sleep(0.2)` 设 `0.05s` 时限。

## 验收

```text
Semaphore：总耗时约 0.3s，而不是 0.1s
timeout / wait_for：均在约 0.05s 后超时
```

`Semaphore` 管数量；`timeout` 管一段代码的总预算；`wait_for` 管一个 awaitable。

## 参考答案

```python
import asyncio


async def demo_semaphore() -> None:
    limit = asyncio.Semaphore(2)

    async def work(index: int) -> None:
        async with limit:
            print("开始", index)
            await asyncio.sleep(0.1)
            print("结束", index)

    await asyncio.gather(*(work(index) for index in range(5)))


async def demo_timeout() -> None:
    try:
        async with asyncio.timeout(0.05):
            await asyncio.sleep(0.2)
    except TimeoutError:
        print("timeout 超时")


async def demo_wait_for() -> None:
    try:
        await asyncio.wait_for(asyncio.sleep(0.2), timeout=0.05)
    except TimeoutError:
        print("wait_for 超时")


async def main() -> None:
    await demo_semaphore()
    await demo_timeout()
    await demo_wait_for()


asyncio.run(main())
```
