# 综合实战

每个文件夹是一道独立练习。你自己新建 `.py` 文件完成，不需要修改教程里的代码；写完运行后，再打开同目录的 `任务.md` 查看参考答案。

建议顺序：

1. [并发启动与总耗时](01-并发启动与总耗时/任务.md)：`await`、`create_task`、`gather`
2. [结果收集与部分失败](02-结果收集与部分失败/任务.md)：`return_exceptions`、`as_completed`
3. [失败即收尾](03-失败即收尾-TaskGroup/任务.md)：`TaskGroup`
4. [首个完成者](04-首个完成者-wait/任务.md)：`wait`、取消
5. [限流、超时与取消](05-限流-超时与取消/任务.md)：`Semaphore`、`timeout`、`wait_for`
6. [同步 I/O 接入](06-同步I-O接入-to_thread/任务.md)：`to_thread`
7. [队列传递工作](07-队列传递工作/任务.md)：`Queue`
8. [广播与互斥](08-广播与互斥/任务.md)：`Event`、`Lock`
9. [CPU 任务与进程池](09-CPU任务与进程池/任务.md)：`ProcessPoolExecutor`

每题先只看“需求”和“验收”，完成后再看参考答案。打印的先后顺序有时受调度影响；重点看总耗时、最终结果和取消行为。
