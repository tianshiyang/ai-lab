# 09 · CPU 任务与进程池

## 需求

- 在模块顶层定义同步函数 `cpu_work(limit)`，计算 `0` 到 `limit - 1` 的平方和，并返回执行它的 PID 与结果。
- 用 `ProcessPoolExecutor(max_workers=2)` 同时提交两项计算。
- 用 `gather()` 收集两个结果。

## 验收

```text
得到两个计算结果
输出的工作 PID 通常不是主进程 PID
```

这题的目的不是追求准确的性能数字，而是确认：CPU 函数运行在独立进程，函数必须放在模块顶层。

## 参考答案

```python
import asyncio
import os
from concurrent.futures import ProcessPoolExecutor


def cpu_work(limit: int) -> tuple[int, int]:
    return os.getpid(), sum(number * number for number in range(limit))


async def demo_process_pool() -> None:
    loop = asyncio.get_running_loop()
    with ProcessPoolExecutor(max_workers=2) as pool:
        results = await asyncio.gather(
            loop.run_in_executor(pool, cpu_work, 200_000),
            loop.run_in_executor(pool, cpu_work, 250_000),
        )
    print(results)


if __name__ == "__main__":
    asyncio.run(demo_process_pool())
```
